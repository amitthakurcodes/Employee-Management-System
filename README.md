\# Employee Management System - ASP.NET Core MVC



A complete \*\*ASP.NET Core MVC\*\* application built with \*\*.NET 8\*\*, showcasing \*\*Master-Details CRUD operations\*\* in an \*\*Employee Management System\*\* with a premium, responsive UI.



This project demonstrates employee record management along with attendance tracking, salary aggregates, and grouped data analysis using ASP.NET MVC architecture (NOT Web API).



\---



\## 📚 Features



\- ASP.NET Core 8 MVC Framework

\- Entity Framework Core 8

\- SQL Server / LocalDB support

\- Master-Details Form Handling (Employee + Attendance)

\- CRUD Operations with Validation

\- Strongly Typed Views

\- Stored Procedure Used

\- Salary Aggregates Dashboard

\- Grouped Data Analysis (by Gender / Joining Date)

\- Responsive Bootstrap 5 UI with custom premium styling

\- Client-side + Server-side validation

\## 🚀 Getting Started



\### ✅ Prerequisites



\- \[.NET 8 SDK](https://dotnet.microsoft.com/en-us/download/dotnet/8.0)

\- Visual Studio 2022

\- SQL Server / LocalDB



\### 🔧 Installation



1\. \*\*Clone this repository\*\*

```bash

&#x20;  git clone https://github.com/amitthakurcodes/Employee-Management-System.git

&#x20;  cd Employee-Management-System

```



2\. \*\*Update your DB connection\*\*

&#x20;  - Open `appsettings.json`

&#x20;  - Edit the connection string with your database info



3\. \*\*Apply EF Migrations \& Create DB\*\*

```bash

&#x20;  dotnet ef database update

```



4\. \*\*Run the app\*\*

```bash

&#x20;  dotnet run

```
